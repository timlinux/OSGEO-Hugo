To request, and manage, your own OSGeo **userid** :

  * **Creating a Userid:** An OSGeo userid can be created using [this form](<https://id.osgeo.org/ldap/create>).
  * **Updating Email:** Visit [this form](<https://id.osgeo.org/ldap/edit>) to update name, email address or password for your userid.
  * **Password Reset:** Lost your password? Visit our [password reset](<https://id.osgeo.org/ldap/reset>) page to reset your password.
  * **Finding a userid:** If you believe you have an OSGeo userid, but have forgotten it, or if you need someone else’s OSGeo user (for instance to assign a bug to them) you can search by common name using [this form](<https://id.osgeo.org/ldap/search>).
  * **Help:** For additional information please visit [OSGeo Userid Help](<https://wiki.osgeo.org/wiki/Osgeo_Userid_Help>) (wiki)

### OSGeo Userid Enabled Services

Currently the following services honour OSGeo-wide userids:

  * [www.osgeo.org](</>): This web site, used by project teams and committee members for content creation. 
    * [members](<https://www.osgeo.org/community/members/>): introduce yourself with a profile page
    * [events](<https://www.osgeo.org/events/>): share an upcoming gathering or activity
    * [resources](<https://www.osgeo.org/resources/>): publications, presentations and videos
    * [service providers](<https://www.osgeo.org/archive-templates/service-providers/>): contact marketing committee ([Add Service Provider](<https://www.osgeo.org/community/getting-started-osgeo/add-service-provider/>))
    * [projects](<https://www.osgeo.org/archive-templates/projects/>): contact incubation committee ([Add OSGeo Website Project Page](<https://wiki.osgeo.org/wiki/Incubation_Committee#Step_1:_Add_OSGeo_Website_Project_Page>))
  * [wiki.osgeo.org](<https://wiki.osgeo.org/>): The OSGeo wiki
  * [trac.osgeo.org](<https://trac.osgeo.org/>): committee and project wiki and issue tracker.
  * [git.osgeo.org/gitea](<https://git.osgeo.org/gitea>): git source control system hosted by the foundation.
  * [svn.osgeo.org](<https://wiki.osgeo.org/wiki/Subversion>): developer subversion source control system hosted by the foundation.
  * [Shell Access to servers](<https://wiki.osgeo.org/wiki/SAC_Service_Status>) can be enabled for OSGeo **userids** by arrangement with the [System Administration Committee](<https://wiki.osgeo.org/wiki/SAC>).
  * [plugins.qgis.org](<http://plugins.qgis.org>): Login to publish to QGIS plugins repository (download is open to everyone without login).
  * The OSGeo’s [Matrix Homeserver](<https://wiki.osgeo.org/wiki/SAC:MatrixSynapse>)
  * The OSGeo’s [Weblate](<https://weblate.osgeo.org>) for translating some OSGeo project documentation
  * OSGeo’s peertube instance [Video](<https://video.osgeo.org>). Everyone can view videos, but to upload videos, you need to log in with your OSGeo account.
  * The OSGeo’s Jitsi instance [meet.osgeo.org](<https://meet.osgeo.org>). Everyone can join a conference, but only users with an OSGeo UserID can create/moderate a meeting
  * [discourse.osgeo.org](<https://discourse.osgeo.org>): OSGeo forum. You can post to the forum using your OSGeo UserID (in addition to other authentication methods).
