[**Mapping and Cartography**](</choose-a-project/mapping-and-cartography/>)

Data visualization, or cartography for mapping professionals, one of the key advantages of a GIS system. Software in this category ranges from desktop solutions, through to web services, web mapping, and mobile solutions.

[**Analysis and Processing**](</choose-a-project/analysis-and-processing/>)

Spatial data analysis and processing is an important benefit to working with a GIS. Software in this category includes everything from desktop solutions and web services and the full range from command line tools to databases and cloud processing.

**Useful Resources**

  * [**Open Web Mapping course developed by Pennsylvania State University, Pennsylvania, USA**. ](<http://www.e-education.psu.edu/geog585>)This course gives you experience with sharing geographic information on the Internet using free and open source software (FOSS) and open specifications. It is an elective course in Penn State’s online geospatial education programs, including the Master of Geographic Information Systems. The lessons are freely visible online as open courseware; however, if you would like to receive official credit for the course and complete the lessons with instructor and peer feedback, you should register for the course through the Penn State World Campus. Technologies used include QGIS, GDAL, OGR, GeoServer, TileMill, Leaflet, and OpenStreetMap.
  * **[Interactive Web Maps course developed by Open Source Geospatial Laboratory team at ETH Zurich, Switzerland](<http://osgl.ethz.ch/training/webmaps/>)**
  * [I**ntroduction to Cartography with Open Source Software**](<https://es.wikiversity.org/wiki/Introducci%C3%B3n_a_la_Cartograf%C3%ADa_con_Software_de_C%C3%B3digo_Abierto>) (in Spanish).
  * **[Geospatial Modeling and Analysis](<https://www.osgeo.org/resources/geospatial-modeling-and-analysis/>)** The course explains digital representation and analysis of geospatial phenomena and provides foundations in methods and algorithms used in GIS analysis.
  * **[UAV/lidar Data Analytics](<https://ncsu-osgeorel.github.io/uav-lidar-analytics-course/>)** The course covers monitoring, analysis, and modeling of 3D landscape change using Unmanned Aerial Systems (UAS) and lidar data.
  * **[OpenLayers Workshop](<https://www.osgeo.org/resources/openlayers-workshop/>)** This workshop is designed to give you a comprehensive overview of OpenLayers as a web mapping solution.
