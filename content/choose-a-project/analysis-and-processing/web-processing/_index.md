# Web Processing

## 

Web processing provides a scalable answer for today’s data volumes; rather than bringing information to your machine, process the information online, where the data is located. Keep an eye out for solutions that are bundled with web services, allowing data to be processed in-place. Look for standards support for automation, or use from your desktop client, along with a deep selection of analysis options.
