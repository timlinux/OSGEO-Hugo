# Catalog

## I have data and web services to share

Catalog services provide enable the search and discovery of data and services as part of a spatial data infrastructure. Key features include support for your organization metadata standards, ease of use and performance. A key feature is OGC Catalog Service for the Web (CSW) compatibility allowing a wide range of software to discover and use your information.
